# Filipe Magalhães Sena

Engenheiro de Software | Arquiteto de Sistemas | Cloud | Engenheiro de IA

### 📝 Resumo de Atuação

*   Especialista em plataformas SaaS corporativas de alta volumetria e microsserviços de backend distribuídos
*   Pioneiro em Engenharia de IA Agêntica, construindo grafos de conhecimento AST e proxies de redução de tokens
*   Forte domínio em arquitetura de serviços Backend-for-Frontend (BFF) utilizando CQRS (.NET 8)
*   Experiência sólida na construção de ecossistemas Microfrontend com React 18, TypeScript e Single-SPA
*   Otimização financeira de nuvem e desenvolvimento de pipelines de dados de alta volumetria (ETL)
*   Projetos relevantes e arquiteturas construídas com C#, Python, Rust, Go e PostgreSQL

### 🧠 Reconhecimentos & Impacto

*   ✅ **Otimização de Custos Cloud:** Remoção de 34,82 TB de dados legados no AWS S3 com precisão de 99,9999%
*   💰 **Economia Direta:** Redução de custos operacionais na nuvem gerando uma economia de ~R$ 54.124,00/ano (US$ 9.840/ano)
*   ⚡ **Zero Downtime:** Construção de motores de migração multithread para bancos legados de alta volumetria
*   🤖 **Eficiência em IA:** Redução do consumo de tokens de IA em até 90% utilizando proxies em Rust e Graphify
