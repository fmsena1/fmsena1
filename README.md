## 📊 Principais Destaques & Impacto Quantificável

- 💰 **Otimização de Armazenamento Cloud & AWS S3:** Desenvolvi um pipeline automatizado de eliminação e arquivamento de dados no AWS S3 em mais de 1.000 clientes corporativos, removendo com sucesso **34,82 TB de dados legados (19,37M de arquivos)** com uma **taxa de precisão de 99,9999%**, gerando uma economia direta de **~R$ 54.124,00/ano (US$ 9.840/ano)**.
- 🏗️ **Backend Enterprise & BFF (.NET 8):** Arquitetura de serviços Backend-for-Frontend utilizando CQRS (.NET 8, MediatR, Dapper, EF Core e PostgreSQL) com performance de resposta em milissegundos para hierarquias complexas de revisões de documentos.
- ⚡ **Pipeline de Dados de Alta Volumetria (ETL):** Construção de motores de migração multithread em Python (`ThreadPoolExecutor`) migrando bancos legados SQL Server/MongoDB para PostgreSQL com zero downtime.
- 🤖 **Engenharia de IA & Otimização de Tokens:** Criação de ferramentas agênticas internas integrando **proxies em Rust (RTK)** e **Grafos de Conhecimento de Código AST (Graphify com mais de 12.000 nós)**, reduzindo o consumo de tokens de IA entre 60% e 90%.
- 🧩 **Ecossistema Microfrontend:** Desenvolvimento de microfrontends modulares em React 18 & TypeScript com Single-SPA, autorização RBAC/ABAC client-side via CASL e sincronização de estado com React Query.
